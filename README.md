# 麦麦值班餐管家 🍔🌙

![麦麦值班餐管家](images/banner.png)

> **晚自习值班到 21:30，谁来管饭？**
> 把值班表丢给它，它算出今晚谁在岗，按人均预算搭配麦当劳套餐、
> 自动领券算最低价，你确认一下，热乎的巨无霸就在路上了。

基于 **麦当劳中国官方 MCP**（`https://mcp.mcd.cn`）开发的 Skill，
为「[麦当劳程序员创意开发大赛](https://github.com/M-China/mcd-developer-innovation-challenge)」而做。

## 这解决什么问题？

中学、医院、运维中心、客服团队……大量岗位实行**轮班制**：

- 排班表在 Excel 里，每天谁值班要自己翻；
- 值班餐预算固定（比如人均 30 元），人工凑单费脑；
- 想吃麦当劳，但要翻菜单、比价格、领优惠券，值班前根本没空。

**麦麦值班餐管家一条龙搞定**：

```
值班表.xlsx ──> 今晚谁值班？ ──> 人均预算多少？
                                     │
        ┌────────────────────────────┘
        v
  查附近门店 + 拉菜单 + 自动领券
        │
        v
  预算搭配算法：每人主餐+饮料，剩余预算换公共小食
        │
        v
  方案确认 ──> 精确算价（含券） ──> 下单/取消
```

## 核心特性

- 📋 **值班表智能解析**：兼容 `2026-10-16` / `2026/10/16` / `10月16日` / 星期制
  等多种写法，表头自动识别，无需修改你现有的排班表；
- 💰 **预算搭配算法**：回溯搜索保证不超预算，优先保证每人「主食+饮料」，
  剩余预算自动换成大家一起吃的小食；
- 🎟️ **省钱闭环**：调用 `auto-bind-coupons` 自动领取麦麦省全部可用券，
  下单前用 `calculate-price` 按券后价精确核算；
- ✅ **未确认不下单**：订单明细复述确认后才创建订单，可随时取消；
- 🔒 **Token 零泄露**：凭据只走连接器配置（环境变量占位），仓库不含任何密钥。

## 安装

### 1. 申请麦当劳 MCP Token

手机号登录 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 配置 WorkBuddy 连接器

WorkBuddy → 左侧「专家·技能·连接器」→ 连接器 → 自定义连接器 → 配置 MCP，
粘贴 [`mcp-config.example.json`](mcp-config.example.json) 内容，
将 `${MCD_MCP_TOKEN}` 替换为你的 Token，保存并启用 `mcd-mcp`。

### 3. 安装本 Skill

把 [`skill/`](skill/) 目录注册为 WorkBuddy 技能，或直接把本仓库克隆到本地，
在 WorkBuddy 对话中引用。

## 使用示例

```text
你：用值班餐管家看看今晚 D:\排课\晚自习值班表.xlsx 谁值班，人均 30 元，
    晚自习结束后外送到学校东门。

管家：今晚（周四）值班 3 人：张老师（高一1班）、李老师（高一3班）、
     王老师（高二2班）。已自动领取 2 张可用券。按人均 30 元搭配：

     | 人员   | 主餐           | 饮料       | 券后价 |
     | 张老师 | 巨无霸套餐     | 可乐(中)   | ¥28.5  |
     | 李老师 | 麦辣鸡腿堡套餐 | 零度可乐   | ¥26.0  |
     | 王老师 | 板烧鸡腿堡套餐 | 冰鲜柠檬水 | ¥27.0  |
     加餐：麦乐鸡 5 块（公共）
     合计 ¥81.5 / 预算 ¥90.0，门店：麦当劳（XX路店），外送至学校东门。
     确认下单吗？

你：确认。

管家：订单已创建，支付链接：...（取餐预计 21:05 送达）
```

命令行方式（不依赖对话，CI/定时任务友好）：

```bash
python src/duty_parser.py --file 值班表.xlsx --today
python src/meal_planner.py --menu menu.json --people 3 --budget 30
```

## 目标用户

- 中小学教务/年级组：晚自习、晚辅导值班老师的晚餐安排；
- 医院、运维、客服等轮班团队的夜班加餐组织者；
- 任何「有排班表 + 有餐补预算 + 想吃麦当劳」的团队。
